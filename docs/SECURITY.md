# Security policy

## Supported versions

| Version | Supported |
| Latest  | Yes       |
| Older   | No        |

## Reporting a vulnerability

**Do not open a public issue for security vulnerabilities.**

Instead, report them privately by emailing `TODO@TODO.com`, with the subject being `[SECURITY]` followed by a brief description.

In this email, include:
- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

### Response

- We will acknowledge the report as soon as we can
- We will shift development focus to fixing the vulnerability, if it's deemed as such
- We will work with you on a fix and coordinate disclosure

## Scope

This policy covers:
- Game client and server code
- Authentication and networking
- Server-side scripting API sandbox escapes

Out of scope:
- Gameplay exploits (report these as regular bugs)
- Third-party mods
- Social engineering
- Godot internal issues
