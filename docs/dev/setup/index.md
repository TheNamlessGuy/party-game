# How to set up the development environment

## Using `just`
1) Install [just](https://github.com/casey/just) if not already installed
2) Run `just initial-setup` in the repository root

Follow the instructions the command outputs on the screen, and then you're done.

## Manually
The `just` command listed above is just a series of calls to other `just` recipes, which in turn are just a series of bash scripts. You can manually reproduce the logic in this flow, if you don't want to install `just`.
