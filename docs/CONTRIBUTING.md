## Developer Certificate of Origin (DCO)

By submitting a pull request, you certify that your contribution is your own original work and that you have the right to submit it under the project's licenses (see [NOTICE.md](NOTICE.md)).

See https://developercertificate.org/ for the full DCO text.

## Code

- Follow [CODESTYLE.md](CODESTYLE.md)
- Add comments for non-obvious logic
- Keep pull requests focused - one feature or fix per PR

## Assets

- Only submit assets you created yourself, or that are CC0/CC-BY/CC-BY-SA-4.0
- Add an entry to [CREDITS.md](CREDITS.md) for third-party assets

## Reporting bugs

Open an issue with:
- Steps to reproduce
- Expected vs actual behavior
- Game version and operating system

For security related issues, please see [SECURITY.md](SECURITY.md).
